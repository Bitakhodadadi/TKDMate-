# TKD Mate — دستیار تمرین تکواندو

برنامه‌ای تحت وب برای ثبت جلسه‌های تمرین تکواندو، مشاهده گزارش ساده و دریافت پیشنهادهای عمومی از هوش مصنوعی بر اساس خلاصه تمرین‌ها.

## امکانات
- ثبت مهارت، مدت و سختی هر جلسه با اعتبارسنجی ورودی
- گزارش تعداد جلسه‌ها، مجموع زمان و میانگین سختی
- ارسال خودکار خلاصه تمرین‌ها همراه سؤال به API
- تنظیم API Key، آدرس پایه و نام مدل (مانند پروژه پالس)
- ذخیره اطلاعات در همان مرورگر (localStorage)
- رابط فارسی، واکنش‌گرا و طراحی تکواندو

## انتشار روی GitHub Pages
1. فایل‌های `index.html`، `style.css`، `script.js` و `README.md` را در ریشه مخزن قرار دهید.
2. در مخزن: **Settings → Pages**.
3. **Deploy from a branch**، شاخه `main` و پوشه `/(root)` را انتخاب کنید.
4. آدرس سایت را باز کنید.

## تنظیم API
- API Key: کلید سرویس هوش مصنوعی
- آدرس پایه پیش‌فرض: `https://api.metisai.ir/deepseek/v1`
- مدل پیش‌فرض: `deepseek-v4-flash`
- برنامه به `{base_url}/chat/completions` درخواست می‌فرستد.

**نکته امنیتی:** کلید در `localStorage` مرورگر ذخیره می‌شود؛ هرگز آن را در کد یا مخزن عمومی قرار ندهید. برای محصول واقعی از سرور امن استفاده کنید.
